# Agent 04 — Microanimations & motion design 2026

## Easings vigentes 2026

| Curva | Valor exacto | Uso |
|---|---|---|
| **iOS drawer/panel** | `cubic-bezier(0.32, 0.72, 0, 1)` | Sheets, modales, paneles, hero entrances |
| **Out-expo (Linear-style)** | `cubic-bezier(0.16, 1, 0.3, 1)` | Reveal scroll, fades, hover lift |
| **Material decelerate** | `cubic-bezier(0, 0.4, 0, 1)` | Tooltips, sidebars que aterrizan |
| **Out-back ligero** | `cubic-bezier(0.34, 1.56, 0.64, 1)` | Toggles, confirmaciones táctiles |
| **Standard in-out** | `cubic-bezier(0.42, 0, 0.58, 1)` | Layout swaps, accordion |

**Para Vértice**: par recomendado = `cubic-bezier(0.32, 0.72, 0, 1)` macro + `cubic-bezier(0.16, 1, 0.3, 1)` reveals/hover. EVITAR `easeInOut` symétrico genérico de Framer Motion default (lee 2022).

Springs solo en drag/swipe. Para entradas declarativas → cubic-bezier por reproducibilidad.

## Duraciones por capa
- **Micro** (feedback inmediato): **120-180ms**. Hover link, focus, button press, checkbox.
- **Componente** (estado interno): **200-320ms**. Card lift, accordion, dropdown, tooltip.
- **Macro** (layout/panel): **400-700ms**. Modal sheet, page slide, sidebar.
- **Hero/cinematográfico**: **800-1200ms**. Solo first paint landing. NO en flujos de entrevista.

## Stagger inter-delay
- Listas cortas (≤6 items, nav): **40ms**
- Listas medianas (form, FAQ): **50-60ms**
- Grids grandes (>12 items): **30-40ms**
- Total nunca >600ms desde primer hasta último item.

## Specs concretos para Vértice

```typescript
// Card hover lift
{
  rest: { y: 0, boxShadow: '0 1px 2px rgba(15,14,14,0.03)' },
  hover: { y: -2, boxShadow: '0 4px 12px rgba(15,14,14,0.04)' },
  transition: { duration: 0.28, ease: [0.32, 0.72, 0, 1] }
}

// Section reveal on scroll
{
  initial: { opacity: 0, y: 16 },
  whileInView: { opacity: 1, y: 0 },
  viewport: { once: true, amount: 0.3 },
  transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1], staggerChildren: 0.04 }
}

// Step transition (View Transitions API)
.css {
  ::view-transition-old(question-card) {
    animation: fade-out 200ms cubic-bezier(0.32, 0.72, 0, 1);
  }
  ::view-transition-new(question-card) {
    animation: fade-in-slide 320ms cubic-bezier(0.16, 1, 0.3, 1);
  }
}

// Input focus
{
  borderColor: 'gold',
  boxShadow: '0 0 0 3px rgba(15, 14, 14, 0.06)',
  transition: '180ms cubic-bezier(0.16, 1, 0.3, 1)'
}

// Error shake
{
  animate: { x: [0, -4, 4, -4, 0] },
  transition: { duration: 0.32 }
}

// CTA primary press
{
  hover: { y: -1, filter: 'brightness(1.04)' },
  active: { scale: 0.97 },
  transitionHover: '160ms ease-out',
  transitionActive: '100ms cubic-bezier(0.32, 0.72, 0, 1)'
}

// Number count-up
animate(motionValue, target, {
  duration: 0.9,
  ease: [0.16, 1, 0.3, 1]
})
// Format: Intl.NumberFormat('es-MX', { currency: 'MXN' })

// Progress fill
{
  width: '0% → N%',
  transition: '480ms cubic-bezier(0.32, 0.72, 0, 1)'
}

// Mask reveal hero
{
  clipPath: 'inset(0 0 100% 0) → inset(0 0 0 0)',
  y: [12, 0],
  transition: { duration: 0.8, ease: [0.16, 1, 0.3, 1] },
  staggerChildren: 0.06
}
```

## prefers-reduced-motion
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
Obligatorio para a11y banca.

## Lo que se siente DATED en 2026
- Custom cursor blob → fuera (B2B)
- Magnetic buttons → fuera en SaaS
- Scroll-jacking → fuera (rompe a11y)
- Parallax exagerado >50% offset → fuera
- Purple→blue gradient hero → fuera (banlist + consenso industria)
- Spring bouncy en TODO → fuera
- Framer Motion easeInOut default → fuera
- Glassmorphism heavy con blur 40px+ → renacido pero "smarter, restrained"
- Noise texture overlay everywhere → declinando

## Lo VIGENTE 2026
- View Transitions API
- Scroll-driven CSS animations nativas
- GSAP ScrollSmoother con scrub
- `interpolate-size: allow-keywords` (height auto animations)
- Motion con propósito comunicativo (Atlassian, Carbon, Material)
